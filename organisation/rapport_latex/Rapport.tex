\section{Introduction}

Dans le cadre de la SAE 4.1, nous avons développé une application Android inspirée du jeu \textbf{Chuzzle}.

Le jeu se base sur une grille de taille 6x6 contenant différents éléments colorés. Le joueur peut effectuer des glissements de lignes ou de colonnes afin de créer des séries d’au moins trois éléments identiques.

Lorsqu’une série est formée :
\begin{itemize}
    \item elle est supprimée,
    \item les éléments au-dessus tombent (gravité),
    \item de nouveaux éléments apparaissent.
\end{itemize}

L’objectif est d’obtenir le meilleur score possible avant qu’aucun coup ne soit possible.

Le projet est structuré selon une architecture \textbf{MVC (Modèle - Vue - Contrôleur)}.

\section{Algorithme de fin de partie}

La partie se termine lorsqu’aucun coup n’est possible.

\subsection{Principe}

L’algorithme consiste à tester tous les déplacements possibles sur la grille.

\subsection{Étapes}

\begin{enumerate}
    \item Parcourir toutes les lignes
    \item Tester les décalages possibles
    \item Vérifier si une série est créée
    \item Répéter pour les colonnes
    \item Si aucun coup ne crée de série :
\end{enumerate}

\begin{center}
\textbf{La partie est terminée}
\end{center}

\subsection{Implémentation}

Cette vérification est réalisée dans la méthode :

\begin{verbatim}
Grille.existeCoupPossible()
\end{verbatim}

Puis utilisée dans :

\begin{verbatim}
MoteurJeu.jouerCoup()
\end{verbatim}
